# Data and materials

This directory contains the derived data and supporting code for the manuscript as
specified in the **Availability of data and materials** section.

## Contents

### `data/audit/`
Derived Parquet tables and audit ledgers generated by the multiverse pipeline.
Each step (01–10) has a CSV ledger and a corresponding Parquet snapshot, plus a
`master_feature_ledger` tracking all processing decisions.

### `data/reports/`
HTML audit reports per pipeline stage, plus the full multiverse result archives
(`multiverse.zip`, `multiverse_endogenous_only.zip`).

### `scripts/`
The three scripts that regenerate the paper's analyses and figures:

| Script | Purpose |
|--------|---------|
| `diagnose_multiverse_instability.py` | Multiverse instability diagnostics |
| `build_paper_tables.py` | All in-text tables |
| `make_paper_figures.py` | All manuscript figures |


## Reproducibility

Running the three scripts above regenerates all supporting analyses, tables, and
figures from the derived data in `data/audit/`. The full multiverse production
pipeline requires the raw Progenesis QI CSV exports and Waters `_HEADER.TXT`
logs, available from the corresponding author on reasonable request.
