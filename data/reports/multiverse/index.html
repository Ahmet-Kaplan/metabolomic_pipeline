Specification curve

How many features each path called shortlisted, sorted ascending. Reading instability (Simonsohn et al. 2020): a wide spread = the answer is sensitive to method choice; a tight band = the methods agree on the size of the answer.

Cross-path agreement (Jaccard)

Pairwise overlap of per-path shortlists. J = |∩| / |∪|. Diagonal is always 1.0; off-diagonal close to 1.0 = paths agree on which features are biomarkers; close to 0 = each path is calling a different set.
